**Academia de Dados Fitness**
-Sistema de gerenciamento de uma academia com o objetivo de organizar e otimizar o controle operacional.

-**Descrição do Projeto**
\nO Academia de Dados Fitness é um sistema de banco de dados relacional desenvolvido para automatizar, organizar e integrar o gerenciamento de uma academia. A finalidade principal é substituir controles manuais por uma base unificada e consistente, permitindo o acompanhamento do vínculo de alunos a planos de matrícula, treinos por personal e o registro em tempo real de acessos (check-ins) na unidade.

\nFuncionalidades
\n•Cadastramento dos alunos
\n•Consulta de alunos e personal
\n•Treinos disponíveis
\n•Check-in de entrada
